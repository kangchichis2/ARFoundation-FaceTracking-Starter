## 🛠 Environment / 개발 환경
* **Unity Version:** 2022.3 LTS (Recommended)
* **AR Foundation:** 5.1.x or higher
* **Platform:** Android (ARCore)
* **Testing Device:** Galaxy S21 / Pixel 6 (ARCore supported devices)

---

## 🚀 Key Features / 주요 학습 내용

### [KO] 한국어
1. **환경 설정:** AR Session, XR Origin 구성 및 패키지 세팅
2. **Face Manager:** 얼굴 감지 시 프리팹을 동적으로 생성하는 법
3. **Core API:** `facesChanged` 이벤트를 통한 실시간 상태 감지
4. **Android 빌드:** ARCore 최적화 설정 (Vulkan 제거, API Level 24+)

### [EN] English
1. **Environment Setup:** Configuring AR Session, XR Origin, and Packages.
2. **Face Manager:** How to dynamically instantiate prefabs upon face detection.
3. **Core API:** Real-time state detection using the `facesChanged` event.
4. **Android Build:** ARCore optimization (Removing Vulkan, API Level 24+).
